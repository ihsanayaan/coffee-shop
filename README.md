#  BrewBean Coffee Shop

Modern bilingual coffee shop web application built with React.js, Tailwind CSS, Context API, and i18next. Designed complete UI/UX prototypes in Figma before development with focus on responsive user experience and RTL/LTR support.

##  Live Demo
🔗 https://coffee-shop-one-woad.vercel.app/

---

#  Features

- RTL/LTR bilingual support
- Modern coffee shop UI
- Dynamic menu system
- Responsive layouts
- Cart persistence
- Smooth user experience
- Mobile-friendly design
- Reusable UI components
- Clean navigation
- Interactive interface
